One funny single-line sport the Olympics rejected: a made-up event, real enough to sound like a broadcast, absurd enough to be funny, and short enough to fit in 200 characters. This program writes that one line to `/output/entry.txt` for the [Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on make.fun.

## Run it

```sh
python3 main.py
```
